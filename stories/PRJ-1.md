### US-PRJ-1: View Projects

**As a** logged-in user,  
**I want** to view a list of my projects with their basic information,  
**So that** I can easily see and manage my projects.

**Acceptance Criteria:**

1. The Projects page displays all projects belonging to the logged-in user.
2. Each project displays:
   - Project name
   - Project key
   - Description
   - Number of backlog todos
   - Active sprint name, if available.
3. If the user has no projects, an empty state is displayed.
4. The empty state includes a "Create your first project" call-to-action.
5. Clicking the call-to-action opens the Create Project dialog.
